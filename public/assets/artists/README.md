# Treast Band — Artist Photos Directory (`public/assets/artists/`)

This directory contains high-resolution portrait photos for all 13 musicians and singers of Treast Band.

## File Naming Conventions:
You can drop new photos directly into this folder using the following filenames:

1. **Ronnie Fung (R.ON)**: `ronnie_fung.jpg`
2. **Budi Muin**: `budi_muin.jpg`
3. **Meme Gend**: `meme_gend.jpg`
4. **Ayu**: `ayu.jpg`
5. **Chang Mazhar**: `chang_mazhar.jpg`
6. **Ce Mon**: `ce_mon.jpg`
7. **Fiq**: `fiq.jpg`
8. **Emma**: `emma.png`
9. **Pia Ramona**: `pia_ramona.jpg`
10. **Latif Rashid**: `latif_rashid.jpg`
11. **Wanie Amir**: `wanie_amir.jpg`
12. **Azirah**: `azirah.jpg`
13. **Atikah Zaki**: `atikah_zaki.jpg`

When you add or replace any file in this directory, the website will automatically load and display your new photo!
